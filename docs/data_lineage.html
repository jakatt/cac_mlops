Lignée des données — du fichier ONISR au modèle en production

Pour n'importe quel modèle entraîné par la plateforme, on remonte à l'octet près jusqu'aux données qui l'ont produit, et on peut les restaurer à l'identique. DVC versionne les données, Git fige chaque version dans l'historique, MLflow relie chaque modèle au dataset exact utilisé pour l'entraîner.

Quatre cycles, quatre versions du dataset, douze modèles

Les métriques ne se comparent pas strictement d'un cycle à l'autre : le jeu de test change à chaque fois (c'est la dernière année disponible). La comparaison qui décide d'une promotion se fait entre modèles évalués sur le même jeu de test (rapports « Comparaison »).

Comment ça marche

Les données ne vont jamais dans Git : Git ne stocke qu'un pointeur de quelques lignes, le contenu est sur S3, adressé par son empreinte.

Git

Un pointeur de 6 lignes

Chaque dataset est représenté par un fichier .dvc : md5, taille, nombre de fichiers. Versionné, diffable, revu comme du code.

Voir le fichier .dvc ↗

DVC

Le contenu sur S3

Le remote Scaleway s3://cac-mlops-data/dvc stocke chaque fichier sous son md5. Une donnée identique n'est jamais stockée deux fois ; une donnée modifiée crée une nouvelle entrée, l'ancienne reste accessible.

Automatique

Versionné par l'ETL

Après validation Pandera et preprocessing, le flow Prefect fait dvc add + dvc push, puis commite le .dvc sur main avec [skip ci] pour ne pas relancer de déploiement.

Restaurer n'importe quelle version

Exemple : retrouver exactement le dataset sur lequel le modèle en production a été entraîné.

# 1. revenir au commit qui a versionné ce dataset
git checkout 75edf98 -- data/preprocessed/cumul_2021_2022_2023_2024.dvc

# 2. télécharger depuis S3 le contenu correspondant à ce md5
dvc pull data/preprocessed/cumul_2021_2022_2023_2024.dvc

# → data/preprocessed/cumul_2021_2022_2023_2024/ identique à l'octet près
Instantané généré à partir de l'historique Git des fichiers .dvc, du registre MLflow et d'une vérification des hachages sur le VPS. Les liens MLflow nécessitent l'accès Tailscale.
